# Create your first workspace

A workspace is an isolated environment where you build and run Codx workflows.

Workspaces help teams separate projects, environments, and operational responsibilities.

## Create a workspace

From the Codx dashboard:

1. Open the workspace selector.
2. Select **Create workspace**.
3. Enter a workspace name.
4. Select an environment.
5. Select **Create**.

For your first project, use:

```text
Workspace: Acme Automation

Environment: Development
