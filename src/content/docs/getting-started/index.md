# Getting started

Codx is an automation platform for connecting your applications, APIs, databases, and internal systems.

With Codx, you can build workflows that react to events, transform data, call APIs, and trigger actions across the tools your team already uses.

This guide walks you through the basics of Codx and helps you build your first working automation.

## What you'll build

By the end of this guide, you'll have a workflow that looks like this:

GitHub issue created
        ↓
      Codx
        ↓
  Check issue data
        ↓
   Send Slack message
