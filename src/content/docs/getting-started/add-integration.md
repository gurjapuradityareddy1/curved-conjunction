# Add an integration

Integrations allow Codx workflows to communicate with external services.

An integration can provide triggers, actions, or both.

Examples include:

1. GitHub.
2. Slack.
3. Jira.
4. PostgreSQL.
5. HTTP APIs.

## Open integrations

From your workspace, open:

```text
Settings → Integrations
